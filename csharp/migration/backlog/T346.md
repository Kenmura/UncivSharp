    - Clean messages: gave-up, snapshot-rejected, internal-error, left and disposed in JoinModel.RefusalText; NetGameSession.SubmitAsync turns session-closed/connection-lost into sentences instead of codes.
    - Harness scenario `reconnect` (real loopback TCP, in-process host, two real clients, frozen host clock): kills the host player's connection and asserts the friend's bar shows "Waiting for Host (offline, 2:00 to reconnect), Friend" and clears it when restored; then kills the friend's connection, asserts the overlay's attempt/backoff/waiting line and the Rejoin button, clicks Rejoin and asserts the overlay goes away with the same seat.
