  - T406 implemented: WorkerAutomation.GetImprovementRanking and GetImprovementBuildingProblems (via a new CanBuildImprovementCached) are memoised in AutomationCache keyed by (tile, improvement); the civ and turn are implicit in the cache's per-turn lifetime (recreated in NextTurnAutomation.AutomateCivMoves, same invalidation as DistanceToClosestEnemyTiles / DangerousTiles). GetImprovementRanking memoises only non-removal improvements: the removal branch recurses with a caller-dependent ignoreImprovements, and the road-plan priority is returned before the memoisation check (a road that falls through to the normal yield path is a pure function and is memoised safely). Safe across workers because ChooseImprovement is already memoised per tile via the existing tileRankings field, so each (tile, improvement) is evaluated with a single unit per turn. ChooseImprovement / GetImprovementPriority / TileHasWorkToDo / FindTileToWork now thread the AutomationCache through; AutomateWorkerAction accepts an optional cache (defaults to a fresh one), matching the UnitAutomation pattern.
    Pure caching, no behaviour change: bench --golden design/perf-golden.json reports small 50 turn hashes identical and medium 200 turn hashes identical (median of 3 runs, all 3 agreeing). No Kotlin fixture; added two C#-only tests (WorkerImprovementEvaluationIsMemoisedInTheAutomationCache, WorkerImprovementMemoisationIsSharedAcrossWorkers).
    Perf (honest): GetImprovementRanking is invoked 2-4x per (tile, improvement) per turn (bestBuildableImprovement + improvementForResource + the comparison + the GetImprovementPriority re-rank), each doing GetStatDiffForImprovement -> GetTileStats -> GetTileStatsBreakdown (T351 measured 1.41 s of the 16.1 s AutomateUnitMoves subtree), so memoising it removes those repeats. GetImprovementBuildingProblems is already once per (tile, improvement) per turn (ChooseImprovement is memoised per tile), so its memoisation is a forward-looking guard rather than an immediate win, and it materialises the full problem set (ToHashSet) instead of the previous short-circuiting Any().
